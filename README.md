# Expense Tracker CLI

Консольное приложение для отслеживания личных расходов. Позволяет добавлять, обновлять, удалять траты, просматривать список и считать общие суммы — в том числе за конкретный месяц. Все данные хранятся в локальном файле `Expenses.json`.

Проект реализован на **Go** без использования внешних библиотек — только стандартная библиотека.

---

## ✨ Возможности

- ➕ Добавление трат с описанием и суммой
- ✏️ Обновление описания и суммы по ID
- 🗑 Удаление траты по ID
- 📋 Просмотр всех трат в виде аккуратной таблицы
- 💰 Подсчёт общей суммы расходов
- 📅 Подсчёт суммы расходов за конкретный месяц
- 💾 Автоматическое сохранение в `Expenses.json`
- 🕐 Автоматическое проставление даты создания
- 🎯 Точная математика без ошибок плавающей точки (подсчёт в центах)

## 🚀 Установка и сборка

1. Склонируйте репозиторий:
```bash
git clone <адрес-репозитория>
cd expense-tracker
```

2. Соберите бинарный файл:
```bash
go build -o expense-tracker main.go
```

3. Запускайте команды через собранный файл:
```bash
./expense-tracker <command> [flags]
```

> **Для Windows** используйте `expense-tracker.exe` вместо `./expense-tracker`.

Альтернативно можно запускать без сборки:
```bash
go run main.go <command> [flags]
```

## 📖 Использование

### Добавить трату

```bash
expense-tracker add --description "Lunch" --amount 20
```

### Посмотреть все траты

```bash
expense-tracker list
```

### Обновить трату

```bash
expense-tracker update --id 1 --description "Lunch with friends" --amount 25
```

### Удалить трату

```bash
expense-tracker delete --id 1
```

### Посмотреть общую сумму расходов

```bash
expense-tracker summary
```

### Посмотреть сумму расходов за конкретный месяц

```bash
expense-tracker summary --month 8
```

## 🗂 Структура данных

Каждая трата хранится как объект со следующими полями:

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `int` | Уникальный идентификатор траты |
| `date` | `string` | Дата создания (`2006-01-02`) |
| `description` | `string` | Описание траты |
| `amount` | `float64` | Сумма траты |

### Пример `Expenses.json`

```json
[
  {
    "id": 1,
    "date": "2026-09-18",
    "description": "Lunch",
    "amount": 20.00
  },
  {
    "id": 2,
    "date": "2026-09-18",
    "description": "Dinner",
    "amount": 35.50
  }
]
```

## ⚠️ Обработка ошибок

Программа корректно обрабатывает следующие ситуации:

- **Файл не существует** — при первом запуске создаётся автоматически.
- **Некорректный номер месяца** — выводится сообщение об ошибке.
- **Пустое описание или отрицательная сумма** — выводится сообщение об ошибке и подсказка по использованию.
- **Отсутствующий обязательный флаг** — выводится сообщение об ошибке и справка команды.

## 🛠 Технологии

- Язык: **Go**
- Хранение данных: **JSON-файл** (`Expenses.json`)
- Использованы только пакеты стандартной библиотеки:
  - `encoding/json` — сериализация/десериализация
  - `os` — работа с файлами и аргументами командной строки
  - `flag` — парсинг флагов командной строки
  - `strconv` — конвертация строк в числа
  - `time` — работа с датами
  - `math` — округление сумм
  - `text/tabwriter` — выравнивание табличного вывода

## 🔧 Известные проблемы и доработки

Следующие моменты требуют полировки:

- [ ] **Тег `json:"amount,string"`** — убрать `,string`, так как число должно храниться как число, а не строка
- [ ] **Отсутствие `default` в `switch` команд** — при вводе неизвестной команда программа молча завершается вместо вывода ошибки
- [ ] **Опечатки `targerId`** — переименовать в `targetId` для читаемости
- [ ] **Отсутствие `return` после обработки** в циклах `update` и `delete` — добавить выход из функции после успешной обработки
- [ ] **Поле `Date` вместо `CreatedAt`** — по ТЗ roadmap.sh требуется `createdAt` с датой и временем, а не только дата

## 🚀 Запланированные фичи

### 1. Категории расходов
Добавить категории для трат (например, `еда`, `транспорт`, `развлечения`) и позволить пользователям фильтровать траты по категории.

**Планируемый синтаксис:**
```bash
expense-tracker add --description "Lunch" --amount 20 --category food
expense-tracker list --category food
expense-tracker summary --category food
```

### 2. Бюджет на месяц
Позволить пользователям устанавливать бюджет на каждый месяц и показывать предупреждение, когда бюджет превышен.

**Планируемый синтаксис:**
```bash
expense-tracker budget set --month 9 --amount 500
expense-tracker budget show --month 9
# Вывод: Budget for September: $500. Spent: $350. Remaining: $150.
# При превышении: WARNING: Budget exceeded by $50!
```

### 3. Экспорт в CSV
Позволить пользователям экспортировать траты в CSV-файл для дальнейшего анализа в табличных редакторах.

**Планируемый синтаксис:**
```bash
expense-tracker export --format csv --output expenses.csv
```
